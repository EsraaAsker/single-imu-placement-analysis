# Single-IMU Placement and Overlap Analysis

A practical notebook and validation workflow for single-IMU placement and overlapping-window diagnostics.

## Contents
The `src/` directory contains the practical scripts, notebooks, dataset manifests, and derived metrics used in this workflow. Raw datasets are not redistributed when they are large or externally licensed.

## Run
```bash
pip install -r requirements.txt
```

Run the Python scripts from the `src/` directory after placing the source dataset at the path described by each manifest or script.
